Rules I Live By

Digital:

  1. Never trust a website that needs JavaScript just to display text
  2. Backup frequently
  3. The best search engine is someone passionate enough about the topic
  4. If a digital tool makes you consult Youtube to find a feature, it's either a flop or the best tool ever

Creativity:

  1. Finish one project before moving to the next
  2. If you're stuck, change environments (computer --> paper, etc.)
  3. Document the process, not just the final product (mistakes are interesting)
  4. If it takes less than 2 mins, do it right now

Music Composition:

  1. A great melody can be sung by a child, but a great harmony keeps an adult listening
  2. Silence is powerful
  3. Write for the performer, not the playback engine
  4. Igor Stravinsky did not write Le Sacre Du Printemps in a day

Jazz Improv:

  1. Repetition legitimizes
  2. Repetition legitimizes
  3. Repetition legitimizes
  4. Rhythm masks note choice
  5. Leave space for the rhythm section to reply
  6. Never outline the root on the downbeat of a new chord
  7. Quote a melody only if you actually respect it

Bassoon:

  1. Never trust a factory-made reed straight out of the box
  2. The whisper key is a contract, not a suggestion
  3. Flick high A, Bb, B, and C, or suffer the consequences
  4. If the ensemble is sharp, you're probably flat
